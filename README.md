# Volunteer Management and Donation Tracking System

A full-stack NGO Management System developed to streamline volunteer management, donation tracking, event coordination, and reporting for organizations.

---

## 🚀 Features

- Volunteer Registration & Approval
- Donation Management
- Donor Tracking
- Event Management
- Program Management
- Expense Tracking
- Reports & Analytics
- Google Authentication
- Role-Based Access Control
- Admin Dashboard
- Public Contact Form
- Razorpay Payment Integration
- MongoDB Data Storage for Contact & Volunteer Forms
- Laravel Sanctum Authentication
- REST API Architecture

## 📊 Architecture

This project follows the MVC (Model-View-Controller) architecture:

- Model → Database logic
- View → React frontend UI
- Controller → Handles business logic and API responses
